# RDK S100P 部署与验收记录

记录截至 2026-11-27。板卡已完成无线联网、EasyTier 组网和 π0.5 单板推理验证，随后停止实验并收存。

## 硬件与复机

- 无线网卡为 Realtek RTL8852CE，装在 J17（M.2 Key E），两根内置天线均已安装。Linux 识别到 PCIe 设备 `10ec:c852`，加载 `rtw89_8852ce`，无线接口为 `wlan0`。
- 装卡和拆天线前关机并拔掉 DC 电源。正常启动时，`DOWNLOAD` 红灯灭、`POWER` 绿灯常亮、`SYSTEM` 橙灯闪烁。若 `DOWNLOAD` 常亮，断电后检查开关是否处于正常启动档。[地瓜硬件手册](https://developer.d-robotics.cc/rdk_s_doc/01_Quick_start/01_hardware_introduction/01_rdk_s100/01_rdk_s100_kit)
- `eth1`（U45）为有线管理口，官方默认地址为 `192.168.127.10/24`。与电脑直连时，可使用同网段内空闲地址。此次曾实测有线链路以 1 Gbps 协商并成功登录 SSH。另一个 `eth0`（U43）可留给 X5 直连。

## 无线与组网

NetworkManager 已保存校园 Wi-Fi 配置并启用自动连接，使用无线网卡的永久 MAC。该设备已完成校园网注册。注册状态与设备 MAC 绑定，若换卡或改 MAC，按校园网流程重新检查注册。校园网 DHCP 地址和 EasyTier 虚拟地址都可能变化。

EasyTier 2.6.4 的 `easytier.service` 已设为开机启动。曾用电脑临时转发完成首次入网，最终已实测在有线链路断开时通过 `wlan0` 直连组网服务器。最后一次复测时板上有两个 EasyTier 实例加入同一个组网，排查地址冲突或路由选择时先用 `sudo easytier-cli peer` 对照实例和虚拟地址。

| 2026-11-27 最后一次短时复测 | 结果 |
| --- | --- |
| 无线关联 | 5 GHz，平均信号约 −56 至 −57 dBm |
| 校园网关 | 40/40 回包，平均 4.1 ms，最高 12.9 ms |
| 外网 HTTPS | 3/3 请求 HTTP 200，耗时 151–223 ms |
| EasyTier 到 X5 | 30/30 回包，平均 38.6 ms，最高 92.6 ms |

此次还通过校园网无线地址成功 SSH 登录。自动校时在最终复测时已同步。采样约 20 秒，尚未验证长期稳定性和收存后的冷启动。

再次使用时，通电后可在板上用以下命令确认当前网络状态：

```bash
ip -br -4 addr
ip -4 route show default
nmcli device status
iw dev wlan0 link
timedatectl show -p NTPSynchronized
systemctl is-active easytier
sudo easytier-cli peer
```

若校园网 DNS 把外部域名解析到注册页面，先核对校园网登记的无线 MAC，再重连 Wi-Fi 刷新 DHCP 租约。若出现证书尚未生效，先检查板上日期。

## π0.5-LIBERO 单板推理

已将 [BLLM 的 π0.5-LIBERO 模型](https://huggingface.co/ruisv/bllm-pi05-libero-224-s100p) 保留在板上：

| 项目 | 板端位置 |
| --- | --- |
| 模型、BPU 图、嵌入和分词器 | `~/models/pi05-libero-224-s100p/` |
| BLLM 环境 | `~/micromamba/envs/bllm/` |
| 已有纯推理脚本 | `~/test_pi05.py` |

```bash
~/micromamba/envs/bllm/bin/python ~/test_pi05.py
```

该测试向策略输入两张测试 RGB 图和英文指令，仅计算动作块。预热后连续 5 次推理均输出有限的 `float32[10, 7]` 动作，耗时 1.099–1.100 秒。仿真闭环、抓取成功率和 Lumos 真机执行均待验证。

## 与 X5 联动

合作方 ACT 链路使用 X5 采集相机与关节状态、S100 推理、X5 执行的结构，已有真机验收记录。本机 S100P 上的 π0.5-LIBERO 接受场景与腕部两路 RGB 和语言指令，输出 `10×7` 的末端增量和夹爪动作。现有 X5 ACT 执行端期望 `100×7` 的关节与夹爪目标。接入前需验证相机视角、坐标系、逆运动学、夹爪映射和超时处理。

若恢复板间直连，可用 S100P 的空闲 `eth0` 接 X5，给两端配置独立私有网段，避开有线管理口所在网段。EasyTier 用于远程管理。板间控制与推理流量优先走直连。板间 IPv4 直连尚未在这台 S100P 上完成配置和验收。
